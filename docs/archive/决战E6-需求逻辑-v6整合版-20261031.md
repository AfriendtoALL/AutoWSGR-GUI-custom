# 决战 E6 全自动刷分需求逻辑规格（v6 整合最终版）

> 本文档为 AutoWSGR 决战模块 E6（第六章）全自动刷分的**唯一权威开发契约**。
> 融合了原 v4 的代码基线评估与 v6 的实机交互提速方案。**若存在冲突，一律以本 v6 整合版的实机逻辑为准。**

---

## 0. 核心机制与全局设定

1. **SL 死锁破局（6-1首次进图）**：如果在 6-1 首次进图弹出购买页时强制杀进程重进，依然停留在购买页，且背包为空、无“关闭”按钮。此时**直接点击最左侧第一张卡（必为考文垂）并点黄色“确定”**即可破局进图。
2. **路线固定**：ADVANCE_CHOICE 永远走最上方，即代码中的 `ADVANCE_CARD_POSITIONS[0]`（收益最大化）。
3. **节点推进**：地图只走一条直线（A→B→…→J），**保留 `chr(ord(node) + 1)` 的字母硬加逻辑**。遇到未知节点 `U`（恢复模式）时保持 `U`，不得推进。
4. **战果与D败**：**完全废弃战果采集**（R6取消）。决战战斗无需识别战斗评级，打完直接推进节点。
5. **阵型与夜战（保留 v4 规则）**：
   - **全局默认**：一律使用**复纵阵**。
   - **特定节点**：仅在 E6-1(B,G,J)、E6-2(C,H,J)、E6-3(D,G,J) 这 9 个节点，使用**梯形阵**。
   - **判定依据**：直接复用代码中的 `DecisiveLogic.is_key_point()`，不再依赖 `enemy_spec.yaml` 的敌方反潜编成。
   - **索敌约束**：无论索敌是否成功，阵型都不改变（保持 `formation_when_spot_enemy_fails` 和 `formation_rules` 为空）。
6. **全局约束**：不泡澡；大破才修，中破不修。

## 1. 小关快照与重置 (State Management)

- **小关级状态**：维护一个 `stage_enter_snapshot`（进入当前小关时的状态快照）。
- **撤退刷新（Reset）**：点击“撤退”并确认后，将点数（score）、拥有的船只及强化等级（ship_levels）、当前副官（instructor）、副官等级（instructor_level）、技能已用记录（skill_used_levels）**全部恢复到快照状态**。
  - *注：血量状态交由游戏引擎管理，代码不回退、不记录。*
- **技能状态回退**：紫貂技能已用状态随小关重置。若 6-2 撤退，原本在 6-2 用过的 Lv.8 技能记录会被清空，重新升到 Lv.8 会再次触发。

## 2. 购买与编队逻辑 (Buy & Fleet)

### 2.1 买船策略（战备舰队获取）
- **绝对优先级**：考文垂（仅 6-1 A 点且未持有时买） > U-47 > U-1206 > 其他潜艇。
- **交互时序**：扫描识别卡面 → 自行计算余额是否足够 → 点击选中目标（卡框变亮） → 点击黄色“确定”按钮 → 界面消失回到地图。
- **刷新限制**：页面没有目标时，点“刷新”（限一次）。
  - **6-1 A 点无目标**：点最左侧第一张卡（考文垂） + 确定，买完进图后立刻点“撤退”重刷。
  - **6-2 A 点无目标**：直接点红色“关闭”退出购买页，然后点“撤退”重刷。
- **潜艇构成**：必须拿到 6 艘潜艇，且必须包含 U-47 和 U-1206。满 6 艘后只重复购买已持有的潜艇（即 +1/+2 强化）。

### 2.2 动态出击与大破修理状态机（核心提速机制）
**满 6 艘潜艇后，不再每次主动点“编队”，利用游戏弹窗和短条驱动修理。**

1. **未满 6 艘潜艇时**（需手动上阵）：
   - 流程：买完船回到地图 → 点“编队” → 把新船放上阵 → 点“快速修理”页签 → 点“全部修理”大按钮 → 点“开始出征”。
2. **已满 6 艘潜艇时**（免编队快捷流程）：
   - 流程：买完船/进图回到地图 → **直接点“出征”**。
   - **情况 A（正常）**：直接切入战斗画面。
   - **情况 B（非旗舰大破）**：弹出确认框（船队中有大破，是否继续） → 点红色“取消” → 点“编队” → 快速修理 → 全部修理 → 出征。
   - **情况 C（旗舰大破）**：屏幕中央出现短条“旗舰处于大破状态，无法出征”（1-2秒后自动消失） → 代码原地等待 2 秒 → 发现仍在地图页（未进战斗） → 点“编队” → 快速修理 → 全部修理 → 出征。
3. **E6-3 J 点特殊流程**：
   - 打完 I 点，选 J 点前进 → 处理完买船界面回到地图。
   - **使用奇尔沙治技能**（只要未进入战斗，技能效果就一直存在，不影响先开技能还是先修船）。
   - 点“编队” → 快速修理 → 全部修理 → 点“开始出征”。

## 3. 副官切换与技能释放 (Instructor & Skills)

### 3.1 副官切换 (R16/R21)
- **时机**：仅在章节总览页，进入小关前。E6-1 / E6-2 为紫貂；E6-3 为奇尔沙治。
- **方法**：利用 3 张真机立绘截图做 SIFT 特征匹配识别。若不符，点击立绘打开弹窗，点击“替换”。若显示“工作中”则直接关闭。

### 3.2 技能触发与买经验 (R13/R14/R15/R17)
- **紫貂技能**：每个战斗节点进图前，OCR 识别当前等级 1 次。
  - 若 `Lv >= 3` 且尚未使用 → 点技能 → **立刻连点“购买 5 经验值”**（只要余额 `>=5` 且未满级） → 标记已用 → 进图。
  - 若 `Lv >= 8` 且尚未使用 → 同上。
- **买经验规则**：单次固定 5 点，可连点。**循环终止只能依靠自算余额（`score >= 5`），不能看按钮状态**。
- **满级判定**：**余额不足时按钮仍亮着**；**只有 Lv.10 满级时按钮才变灰**。使用 `PixelRule` 取色判断按钮灰态，代替 OCR 判满级。
- **奇尔沙治技能**：见 2.2 第 3 点（J 点战斗前使用）。
